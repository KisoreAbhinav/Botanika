# Backend boundary

This directory will hold one FastAPI-based **modular monolith**. The modules
under `src/botanika/` separate responsibilities without turning a single Pi into
an unnecessarily complex fleet of microservices.

The authoritative module ownership and dependency rules are documented in
[`docs/PI_ARCHITECTURE_AND_ROADMAP.md`](../docs/PI_ARCHITECTURE_AND_ROADMAP.md).
