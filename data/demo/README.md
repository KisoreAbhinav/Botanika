# Weed detector demo image

`weed-in-maize-field.jpg` is an unmodified Wikimedia Commons photograph showing broadleaf weeds growing among maize/corn plants. It is used as a crop-versus-weed field-scene fixture for the Botanika Weed Detection Beta demo.

- Source page: https://commons.wikimedia.org/wiki/File:Mais_Unkraut_738.JPG
- Original image: https://upload.wikimedia.org/wikipedia/commons/7/72/Mais_Unkraut_738.JPG
- Author: Don Manfredo
- License: CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0/)
- Retrieved: 2026-09-05

The detector result is stored in `weed-in-maize-field-result.json`; it reports one generic `weed` cue at the model's confidence and does not claim species-level identification.
